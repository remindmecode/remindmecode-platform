# 🎯 Objetivo

Descrever, em nível macro, os principais casos de uso da plataforma, permitindo visão consolidada das funcionalidades institucionais, dos atores envolvidos e da evolução funcional do produto.

---

# 🧠 Contexto

Os casos de uso representam interações relevantes entre usuários institucionais e a plataforma, servindo como base para:

- detalhamento funcional;
- modelagem comportamental;
- definição de fluxos operacionais;
- priorização evolutiva;
- elaboração de casos de uso detalhados.

# 🔄 Evolução dos Casos de Uso

Os casos de uso apresentados representam a visão funcional inicial da plataforma e poderão evoluir conforme:

* expansão dos módulos institucionais;
* amadurecimento operacional;
* evolução analítica da solução;
* novas necessidades institucionais;
* incremento das capacidades da plataforma.

Os casos de uso detalhados deverão derivar diretamente desta visão macro.
